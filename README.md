# Botstudio landing page

Responsive, static landing page for the Telegram AI bot builder.

## GitHub Pages

In repository settings, open **Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. The `.nojekyll` file ensures static assets are served without Jekyll processing.

The calls to action point to [@ZayavkaFlowBot](https://t.me/ZayavkaFlowBot).
