# BotForge brand book

## Brand

**Name:** BotForge  
**Slogan:** Создай бота за 5 минут.  
**Positioning:** ИИ-конструктор Telegram-ботов для быстрого запуска бизнес-идей без кода.

## Color palette

| Token | Color | Use |
|---|---|---|
| --brand-primary | #00F0FF | Neon turquoise highlights and calls to action |
| --brand-secondary | #0033FF | Deep blue gradients and supporting accents |
| --brand-bg | #0B0E14 | Main dark background |
| Text | #F7F7FB | Main readable text |
| Muted text | #A1A4B5 | Supporting copy |

## Typography

The site uses **Space Grotesk** for headings and the BotForge wordmark, with **DM Sans** for body text. Both are loaded from Google Fonts. The wordmark uses a bold weight with tight letter spacing and a cyan-to-blue gradient.
